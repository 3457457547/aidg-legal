English

This game runs AI inference on the user's local PC and stores game data locally. It does not automatically send gameplay prompts or AI-generated dialogue to the developer. Steam achievements and, in versions that support it, custom-character Steam Cloud synchronization use Valve's services as described below. When the game is purchased through a store platform, the developer may receive purchaser/order information made available by that platform.

No Automatic Collection by the Developer

The game does not automatically submit in-game personal information, gameplay history, save data, usage statistics, prompts, AI-generated responses, or crash reports to the developer. This does not mean that the game has no local storage or Steam platform integration.

Local Data Storage

The game stores data on the user's PC, including:

  • Game settings (language, sound, etc.)
  • Save data (current run progress, achievements, character unlocks)
  • Custom characters, selected names and traits, questionnaire answers, adjusted images, and saved lineups in versions that support these features
  • AI model files bundled with the game (stored in the installation directory)
  • Optional recovery-downloaded AI model files (stored in the user's userData directory) if the bundled model is missing

Removing the local userData directory deletes the data stored there; this does not delete Steam achievements or copies held in Steam Cloud. Cloud data may be downloaded again when synchronization is enabled. The bundled model file is removed with the game installation.

Custom Characters and Steam Cloud

In versions that support custom-character synchronization, when Steam Cloud is available and enabled for the account and the game, saved custom-character data and lineups are stored with Valve and synchronized through the user's Steam account. This includes saved names, character settings, questionnaire answers where present, adjusted uploaded images, and identifiers and revision information used for synchronization. Gameplay prompts and AI-generated dialogue are not part of this custom-character Cloud data.

The feature does not publish uploaded images to other players or provide an image-sharing service. Steam Cloud is separate from the game's local AI inference and from Steam achievements. Cloud synchronization requires a network connection; local AI inference does not. Steam Cloud can be disabled globally or for this game in Steam settings. Disabling synchronization does not by itself delete existing Cloud copies.

For the images you may use, see the Image Use Terms.

AI Model and Local Inference

This game uses a locally-installed Large Language Model (LLM) to generate AI character dialogue. Official builds include the model file with the game. If the bundled model is missing, the game may offer a one-time recovery download from a public model repository (Hugging Face). During that recovery download, Hugging Face or network providers may receive ordinary network metadata such as IP address and request information under their own privacy policies. In normal official builds:

  • All AI inference runs on the user's hardware.
  • Gameplay prompts and AI-generated dialogue are processed locally, not sent to a hosted AI service. Steam platform services are described separately above and below.
  • No internet connection is required for gameplay.

Steam Platform

This game is distributed via Steam (Valve Corporation). Steam itself may collect data (purchase history, playtime, achievements, etc.) according to Steam's own Privacy Policy. Please refer to:
https://store.steampowered.com/privacy_agreement/

The game submits achievement identifiers to Steam to unlock or synchronize achievements. Valve handles Steam platform data under its own policy. Information available through Steam's developer tools and APIs depends on the service and the user's privacy settings.

Other Store Platforms

If this game is purchased or downloaded through itch.io or BOOTH, those platforms may collect account, purchase, download, payment, or access-log data according to their own privacy policies. Depending on the platform's seller tools, the developer may be able to view purchaser or order information such as name, email address, country/region, payment/order IDs, or access logs. The developer does not receive gameplay prompts, AI-generated dialogue, or local save data from those platforms.

Third-Party Services

This game does not use any third-party analytics, advertising, or tracking services.

Children's Privacy

This game is not directed at children under 13. The developer does not automatically collect in-game data from users; the local storage and Steam features described above still apply.

Changes to This Policy

This privacy policy may be updated to reflect changes in the game or applicable laws. The latest version will always be available at the URL specified on the Steam store page.

開発者への自動送信について

本ゲームは、ゲーム内の個人情報、プレイ履歴、セーブデータ、利用統計、プロンプト、AI生成された応答、クラッシュレポートを開発者へ自動送信しません。PC内への保存やSteamとの連携を行わないという意味ではありません。

ローカル保存データ

本ゲームは、以下のデータをお客様のPC内に保存します。

  • ゲーム設定（言語・音量等）
  • セーブデータ（現在の進行状況・実績・キャラクター解放状況）
  • 対応する版では、自作キャラクター、選んだ名前と人物設定、質問の回答、調整後の画像、保存した編成
  • ゲーム本体に同梱された AI モデルファイル（インストール先ディレクトリに保存）
  • 同梱モデルが見つからない場合の復旧用ダウンロード済み AI モデルファイル（userData ディレクトリに保存）

PC内のuserDataディレクトリを削除すると、その中のデータが削除されます。この操作ではSteam実績やSteam Cloud上のコピーは削除されず、同期が有効な場合はCloudから再取得されることがあります。同梱モデルファイルはゲーム本体のアンインストール時に削除されます。

自作キャラクターとSteam Cloud

自作キャラクターの同期に対応する版では、Steam Cloudが利用可能で、アカウントと本ゲームの両方で有効な場合、保存した自作キャラクターと編成をValveのサーバーに保存し、お客様のSteamアカウントを通じて同期します。保存した名前、人物設定、質問の回答（保持している場合）、調整後のアップロード画像、同期に使う識別子・更新情報が含まれます。プレイ中のプロンプトやAI生成台詞は、この自作キャラクターのCloudデータには含めません。

本機能はアップロード画像を他のプレイヤーへ公開せず、画像共有サービスを提供しません。Steam Cloudは、PC内でのAI推論やSteam実績とは別の機能です。Cloud同期には通信が必要ですが、PC内でのAI推論には不要です。Steamの設定で、全体または本ゲームのCloud同期を無効にできます。同期を無効にするだけでは、既にCloudにあるコピーは削除されません。

使用できる画像については、画像の利用条件をご覧ください。

AI モデルとローカル推論

本ゲームは AI キャラクターの台詞生成に、ローカル PC にインストールされた大規模言語モデル（LLM）を使用します。正式配布版にはモデルファイルが同梱されています。同梱モデルが見つからない場合のみ、復旧手段として公開モデルリポジトリ（Hugging Face）からの一度きりのダウンロードを案内する場合があります。その復旧ダウンロード時には、Hugging Face または通信経路上の事業者が、各自のプライバシーポリシーに基づき IP アドレスやリクエスト情報など通常のネットワークメタデータを受け取る場合があります。通常の正式配布版では:

  • すべての AI 推論は お客様のハードウェア上で実行 されます。
  • プレイ中のプロンプトとAI生成台詞はPC内で処理し、外部のAIサービスへ送信しません。 Steamのサービスについては前後の節で説明しています。
  • ゲームプレイにインターネット接続は不要です。
